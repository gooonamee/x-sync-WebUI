同步書籤與點讚指南

1
去 Chrome WebStore 安裝下載

前往 Chrome WebStore 頁面 安裝下載「X sync」擴充功能，點選「加到 Chrome」即可完成安裝。

2
前往 x.com 點擊同步

在已登入的 x.com 書籤或點讚頁面點擊 X sync 圖示，選擇「一次同步 50 筆」或「全量同步」，右下角將顯示即時進度浮窗。

3
檢視本地同步資料

推文與多媒體檔案將自動過濾重複，即時寫入本機 SQLite 資料庫，切換回本面板立即呈現！
